安装软件源

以下命令在运行 ImmortalWrt 25.12.2 的设备上执行。软件源索引与所有包均由 CombineWRT 签名。

1. 安装公钥

wget -O /etc/apk/keys/combinewrt-feed.pub.pem https://wuyuzaddd.github.io/combinewrt-packages/keys/combinewrt-feed.pub.pem

公钥地址：https://wuyuzaddd.github.io/combinewrt-packages/keys/combinewrt-feed.pub.pem

2. 添加软件源

echo "https://wuyuzaddd.github.io/combinewrt-packages/x86_64/packages.adb" >> /etc/apk/repositories
apk update

软件源必须指向 packages.adb 本身；使用目录地址会返回 404。

3. 安装软件包

apk add luci-app-fwlive luci-app-store luci-app-substore luci-lib-taskd luci-lib-xterm taskd

也可以只安装需要的包：apk add luci-app-store。

常见问题

404
软件源地址必须包含 /x86_64/packages.adb，不能只写到目录。
签名错误
确认公钥位于 /etc/apk/keys/，且索引没有被中间人修改。
架构不匹配
本软件源只提供 x86_64 版本；其它架构请勿添加。

索引被篡改或包内容与索引不一致时，apk 会拒绝安装。这是预期行为，不要使用 --allow-untrusted 绕过。
